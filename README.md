## OpenCode Session

After cloning, start OpenCode from repository root and select current machine:

- `/bigpc`: Windows host with Void Linux WSL2, 16 CPU cores, 16 GiB RAM, GPU.
- `/smallpc`: native Void Linux, 4 CPU cores, 3.8 GiB RAM, no swap.

Commands set session context only. Resource preflight remains authoritative. See `docs/agents/machine-profiles.md`.
