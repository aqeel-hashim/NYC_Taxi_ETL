## OpenCode Session

After clone, start OpenCode from repo root; select current machine:

- `/bigpc`: Windows + Void Linux WSL2, 16 CPU cores, 16 GiB RAM, GPU.
- `/smallpc`: native Void Linux, 4 CPU cores, 3.8 GiB RAM, no swap.

Commands set session context only. Resource preflight authoritative. See `docs/agents/machine-profiles.md`.
