Assignment 1:
Focus: Batch ETL, Data Modeling, SQL, Python, Local Orchestration, and Basic Monitoring.

1. Objective
Build a local, automated batch ETL pipeline that downloads taxi trip data, transforms it into
a clean dimensional model (Star Schema), loads it into a local database, and exposes key
business metrics through a lightweight dashboard.

3. Detailed Tasks for the Candidate
1.​ Task 1: Linux & Setup (Bash): Write a Bash script (setup.sh) that automates creating a
Python virtual environment, installing dependencies, and spinning up a local
PostgreSQL database using Docker. Use curl or wget to programmatically download at
least two months of NYC Taxi data.
2.​ Task 2: Data Modeling & Database Setup: Design a Star Schema optimized for analytical
queries. Create a schema.sql file defining a central Fact Table (fact_taxi_trips) and at
least three Dimension Tables.
3.​ Task 3: Python ETL & Orchestration: Build an ETL pipeline using a modern
orchestration tool. Extract & Clean using Python. Transform & Load into your structured
SQL Star Schema tables.
4.​ Task 4: Monitoring & Logging: Implement structured Python logging to capture pipeline
start/end times, row counts processed, and explicit error handling. Configure the
orchestration tool to alert/log status on failures.
5.​ Task 5: SQL & Dashboarding: Write SQL queries to calculate: Average fare amount per
mile, Peak hours for taxi rides, and Total revenue by payment type. Build a single-page
Streamlit or Superset dashboard.

Assignment 2:
Focus: Real-time Streaming Architecture, Heavy Kafka integration, High-Level Observability,
Scalability, and Advanced Data Engineering.

1. Objective
Architect and implement a local real-time data ingestion and processing pipeline. Simulate a
live stream of taxi ride events into Apache Kafka, consume and aggregate the events in real
time, store them efficiently, and build an observability layer.

3. Detailed Tasks for the Candidate
6.​ Task 1: Infrastructure Setup & Kafka Configuration: Provide a docker-compose.yml that
provisions a multi-broker Kafka cluster locally. Configure a Kafka topic named
taxi-trips-stream with multiple partitions.
7.​ Task 2: Stream Producer (Python): Write a Python script that reads the downloaded NYC
Parquet/CSV data and acts as a "Stream Producer," pushing records into the Kafka topic
at a rate of 10–50 events per second.
8.​ Task 3: Stream Ingestion, Processing & Modeling: Write a streaming application to
consume events from the topic. Calculate a sliding window aggregation. Write the raw
streaming events into an analytical table while upserting aggregations.
9.​ Task 4: End-to-End Monitoring & Observability: Expose application metrics to
Prometheus. Build a Grafana dashboard that visualizes cluster health, consumer lag, and
pipeline throughput.
10.​Task 5: System Architecture Document: Submit a README.md containing a production
architecture design detailing how to scale this local setup to handle 50,000 events per
second on a cloud provider.
